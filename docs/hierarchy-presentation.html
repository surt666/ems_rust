Node-formula roll-up

Sensors are plain raw values — no formula, no per-sensor factor. A sensor knows only which resource it measures. Hierarchy nodes carry formulas that declare a (resource, purpose) output and combine descendant sensors with coefficients. Pick a resource and a purpose to watch the same tree answer a different question.

What changed: the formula moved off the sensors and onto the nodes — and split into two independent axes. Resource (energiart) is what the meter physically measures; it stays on the sensor. Purpose (formål) is what the energy is spent on; it is declared by the node, because the same meter's kWh can be space heating here and DHW there. There is no “metric” axis: CO₂ and cost are derived from (resource, purpose) at read time, so the demo's old per-sensor emission factor is gone.
Terms are weighted Every term is reference × coefficient. Include = 1, subtract = −1, exclude = 0, apportion = 0.28, convert = 10.45. Purely linear, so it commutes with hour/day bucketing.
Overrides only A formula lists only what differs from the default. Any sensor nobody mentions still counts at weight 1 — so attaching a meter always moves the numbers and nothing is silently dropped.
Total & unallocated The job always emits total (Σ of everything below, honouring weight overrides) and unallocated (total − claimed). Partial instrumentation shows up as a number instead of disappearing.
Claims propagate up A purpose claimed on an area is claimed for its building, property and company too — purpose series roll up the tree exactly like total does. A sensor may be claimed for a given purpose by one node only.
Derived rows When the declared output resource differs from the sensors' — gas m³ × brændværdi × virkningsgrad, or el × COP — the row is derived. It is delivered energy, not metered consumption, so it never folds into any total.
Straight from Energihåndbogen Bimåler: DHW is metered, space heating = total − DHW. GUF/GAF: with no submeter, the degree-day-independent part is a standard 28 % of annual heat. Both are just weighted terms.
